# НОЧЬ ЗА СКОЛЬКО? 🌙

Мобильная веб-игра: угадывай цену ночи посуточной аренды в Калининграде по объявлениям Авито. 10 раундов, «аура» за точность, ранги и рекорд. Тиффани + нео-брутализм.

## Как запустить локально

Сервер не нужен — просто открой `index.html` в браузере:

```bash
open index.html        # macOS
# или двойной клик по файлу
```

Данные лежат в `data.js` и подключаются обычным `<script>`, поэтому игра работает и с `file://`.

## Как выложить на GitHub Pages

1. Запушь репозиторий на GitHub (ветка `main`).
2. Открой **Settings → Pages**.
3. Source: **Deploy from a branch**, Branch: **main**, папка: **/ (root)** → Save.
4. Через минуту игра будет на `https://<username>.github.io/<repo>/`.

## Как обновить данные

1. Положи свежий CSV с названием `creative_hse_2026 - жилье клнгрд.csv` (та же структура колонок) в корень.
2. Запусти:

```bash
python3 build_data.py
```

Скрипт перезапишет `data.js`. Объявление «тематическое помещение 21+» (13 000 ₽) выбрасывается автоматически.

## Структура

- `index.html`, `styles.css`, `app.js` — игра (без фреймворков и сборки)
- `data.js` — сгенерированные данные (`window.LISTINGS`)
- `build_data.py` — CSV → data.js
- `creative_hse_2026 - жилье клнгрд.csv` — исходные данные

Учебный проект, данные: Авито.
